# 2

A minimal demo project.

## Usage

```sh
python3 demo.py           # Hello, world!
python3 demo.py Atif      # Hello, Atif!
```

## Random bar

```sh
python3 bar.py            # fills a bar to a random 0–100%
```

Example output:

```
[#################-----------------------]  43%
```

## Browser bar

Open `bar.html` in any web browser. The bar fills to a random 0–100%; click **Roll again** for a new number.
